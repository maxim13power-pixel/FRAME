---
name: Безопасность логов при запуске
description: Правило для диагностических сообщений серверных приложений.
---

Диагностические логи при старте не должны выводить полные строки подключения, токены, пароли или другие секреты.

**Why:** Стартовые логи видны в истории workflow и могут быть доступны шире, чем исходный код или секреты окружения.

**How to apply:** Логируй только безопасные признаки состояния, например факт загрузки конфигурации, имя окружения и результат подключения без значений секретных переменных.
