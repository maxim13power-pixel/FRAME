# Ручные тесты: доступы, цены, справочники, сметы

Чек-лист для регрессии руками. Автоматически часть проверяется скриптом
`npm --prefix backend run test:api` (43 проверки), но отчёты, склад, аренда, шаблоны,
фиксации и вёрстка — только вручную.

## Как готовить окружение

- Три профиля браузера (или обычное + инкогнито): **админ**, **прораб**, **наблюдатель**.
- Объект A с проектом A1 и материалом с ценами; объект B — «свой» объект второго человека
  (чтобы проверить смешанные роли).
- Приглашения — ссылкой, срок 2 часа.

---

## 1. Деньги: кто что видит (P0)

Проверять в двух ролях: **наблюдатель** и **прораб со скрытыми ценами**.

| # | Шаг | Ожидаемо | Где возможна ошибка |
|---|---|---|---|
| 1.1 | Открыть смету объекта A | Ни цены, ни суммы, ни «Итого»; количество и прогресс видны | `materials` может вернуть цены в новом поле/эндпоинте |
| 1.2 | «Главная» → деньги | Смета/факт = 0, KPI (объекты/проекты/материалы) видны | `recentFixes.amount` — это объёмы, не деньги, не путать |
| 1.3 | «Аналитика»: бюджет/факт, тренд, перерасход | Бюджет/факт = 0; если есть свой объект — только его цифры | аналитика считает по «доступным» объектам, а не «где вижу цены» |
| 1.4 | Справочник: список | Свой «Мой справочник» с ценами; справочник A — отсутствует | фильтр `listCatalogs` |
| 1.5 | Справочник A по прямой ссылке `/price-list/:id` | Позиции есть, цены «—» | маска по позициям |
| 1.6 | Правка позиции в чужом справочнике A | 403 «Цены скрыты…» | `updateItem` |
| 1.7 | Правка позиции в своём справочнике | Разрешено (наблюдателю тоже) | `updateItem`/`createItem` |
| 1.8 | Пересчёт: превью | 403 «Вам скрыты цены…» | `preview` |
| 1.9 | Пересчёт: история | 403/скрыта (№359) | `history` — раньше отдавал план «до/после» |
| 1.10 | Отчёты (если есть): список, карточка, PDF/XLSX | Без сумм и цен | отчёты по проекту + экспорт |
| 1.11 | Склад: позиции с ценой | Цены скрыты | `warehouse` может не фильтровать |
| 1.12 | Аренда: суммы | Скрыты | `rentals` |
| 1.13 | Шаблоны смет с ценами | Без цен | `estimate-templates` |
| 1.14 | Фиксации с ценой | Сумма фиксации скрыта | `materials/:id/fixes` |
| 1.15 | Импорт/экспорт прайса | Свой — с ценами; чужой скрытый — без цен/запрет | `price-list-import` |
| 1.16 | Снимок удалённого участника | Содержит только то, что можно было видеть | `snapshots` |

| # | Шаг | Ожидаемо |

## 5. Мобилка и UX (P2)

- 360 px: модалки объекта/проекта, панель участников, две кнопки приглашения, «—» в справочнике.
- Длинные имена объектов/людей в заголовках и карточках.
- После смены роли/цен — обновление без F5 (где кэш).
