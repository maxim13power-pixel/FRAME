PROJECT FRAME — SaaS для строительных смет: объекты → проекты → сметы (материалы/работы),
фиксации объёмов, склады, бригады, аренда, справочники цен, отчёты, аналитика.

- Backend: NestJS + Prisma 5.22 + PostgreSQL (`127.0.0.1:5433`, БД `frame_db`), порт **3000**.
- Frontend: React 19 + MUI 6 + Vite, порт **5000**.
- Репозиторий: `C:\PROJECTS\frame-app`.
- Владелец говорит по-русски; интерфейс, комментарии и коммиты — на русском.

## 5. Особенности окружения

- Backend в watch (`npm run start:dev`). Не убивать дочерний процесс по одиночному PID —
  только `taskkill /PID <pid> /T /F` по процессу `npm-cli.js run start:dev`.
- Перед `prisma generate` backend нужно остановить (Windows блокирует файлы клиента).
- `DATABASE_URL` — только `127.0.0.1`, не `localhost` (иначе P1001).
- Схему меняли с остановкой backend: `prisma db push --accept-data-loss` (снят старый unique
  `[name, kind]`) + `generate` + миграция категорий + `start:dev`.
- Для production: свежая резервная копия + проверенный diff миграции, без `db push` как есть.

## 6. Открытые вопросы для обсуждения (следующий чат)

1. **SQL-агрегаты списка проектов.** Сейчас `projects.service.list` выгружает строки материалов
   и суммирует в JS. План — `material.groupBy` (суммы/количество) без UI-изменений. Оценить риск
   и нужность.
2. **Пагинация больших списков.** Варианты: «Показать ещё» (offset/cursor), бесконечная прокрутка,
   виртуализированная таблица. Влияет на выделение строк, массовые действия, экспорт и фильтры.
   Нужно решение владельца по UX.
3. **PDF-содержимое.** Сейчас проверен только статус/content-type; текст PDF не извлекали.
   Вариант: `pdf-parse` в тесте или ручная проверка скачанного файла.
4. **Границы XLSX-лимитов.** Тесты проверяют превышение, но не «ровно 25 МБ / 20 000 строк».
   Нужны ли позитивные тесты на границе.
5. **Визуальный смоук**: «Мой справочник» после миграции категорий, новые ответы с маскировкой,
   busy-кнопка фиксации, ссылки поддержки в «Помощи».
6. **Прочее P2**: N+1 в других экспортах, индексы под горячие запросы, стратегия миграций.
