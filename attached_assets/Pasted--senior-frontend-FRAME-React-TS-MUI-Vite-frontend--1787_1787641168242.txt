🔧 ШАГ 1: App.tsx — Find/Replace (не переписывать весь файл!)
═══════════════════════════════════════════════════════════
В верхней части файла, где import'ы страниц, ДОБАВЬ одну строку (если её ещё нет):
  import Landing from './pages/Landing';

В <Routes> НАЙДИ блок корневого маршрута "/" (он выглядит ОДНИМ ИЗ вариантов):
  • <Route path="/" element={<ProtectedRoute><Dashboard /></ProtectedRoute>} />
  • <Route path="/" element={<ProtectedRoute><Home /></ProtectedRoute>} />
  • <Route path="/" element={<Navigate to={token ? ... : '/login'} />} />
  • <Route path="/" element={token ? <Navigate ... /> : <Navigate to="/login" />} />

ЗАМЕНИ ЭТОТ БЛОК НА:
  <Route
    path="/"
    element={
      token ? (
        <ProtectedRoute>
          <Home />
        </ProtectedRoute>
      ) : (
        <Landing />
      )
    }
  />

УБЕДИСЬ что вверху файла есть import Home и import ProtectedRoute
(они уже должны быть — не удаляй).

ЕСЛИ в App.tsx есть отдельный <Route path="/landing" ... /> — УДАЛИ эту строку ЦЕЛИКОМ.
Лендинг теперь живёт только на "/".
